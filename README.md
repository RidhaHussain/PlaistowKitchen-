Project Overview

This project is a simple website created for the Silvertown Studio work-experience project. It is designed to help volunteers book shifts, check the kitchen rota and manage food stock.

Features

Home page: Provides navigation to the main features.

Shift Booking: Allows volunteers to enter their name, date and shift time.

Stock Cupboard: Displays food items and allows users to update quantities or add new items.

Tonight's Rota: Displays the current shift bookings.

Technologies Used

HTML

CSS

JavaScript

Browser localStorage

GitHub and GitHub Pages

How to Access the Website

Open the published GitHub Pages link to use the website. Alternatively, download the project files and open index.html in a web browser.

How to Use the Website

Open the home page.

Select Book Shift to enter volunteer booking details.

Select Stock Cupboard to view or update food quantities.

Select Tonight's Rota to view the shift bookings.

Data Storage and Limitations

The website uses browser localStorage to save information on the device and browser being used. The information is not automatically shared with other devices. The website is a prototype and does not have a shared database or a full user login system. Fictional details should be used when testing.

Testing

The website has been tested, and screenshots and a test plan have been prepared as project evidence. The test results should be recorded, including any problems found and changes made.

Future Improvements

Possible improvements include adding a secure shared database, creating a coordinator login, improving rota management and carrying out further accessibility testing.
